# Input Directory

Place your parking lot images and videos here for analysis.

## Supported Formats

### Images
- JPG / JPEG
- PNG

### Videos
- MP4
- AVI
- MOV

## Tips
- Use overhead or angled parking lot images for best results
- Higher resolution images provide better detection accuracy
- For video analysis, MP4 format with H.264 codec is recommended
- Images should clearly show parking spaces and vehicles
